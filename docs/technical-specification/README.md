# Техническое задание на разработку FinTax Pro

## 1. Назначение системы
Автоматизация формирования, проверки, подписания и отправки налоговой отчётности в ФНС.

## 2. Основные функции
- Импорт данных из книг покупок/продаж (Excel, 1С, API)
- Автоматическое заполнение декларации по НДС
- Проверка контрольных соотношений ФНС
- Выгрузка в XML
- Подписание ЭЦП (главбух + руководитель)
- Отправка в ФНС через оператора ЭДО
- Получение и обработка квитанции
- Журнал отправки со статусами

## 3. Ролевая модель
- Бухгалтер — создание и редактирование отчётов
- Главный бухгалтер — первая подпись ЭЦП
- Руководитель — утверждение и вторая подпись
- Администратор — настройка пользователей
