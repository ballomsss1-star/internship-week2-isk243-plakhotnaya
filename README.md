# FinTax Pro

## Предметная область: Бухгалтерский учёт и налоги

Проект по автоматизации формирования, проверки, подписания и отправки налоговой отчётности (НДС, баланс, декларации) в ФНС для малых и средних предприятий.

## Технологии проекта

**Бэкенд:** Python, FastAPI, PostgreSQL, SQLAlchemy, Celery, Redis, JWT

**Фронтенд:** React, TypeScript, Vite, Ant Design, Axios

**Десктоп-компонент:** Electron, КриптоПро (ЭЦП)

**Инфраструктура:** Docker, GitHub Actions, Nginx

**Интеграции:** API ФНС, 1С (Excel), операторы ЭДО
