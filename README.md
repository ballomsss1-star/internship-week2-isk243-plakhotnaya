# SCM Predictor Pro

## Предметная область: Логистика и управление цепочками поставок (SCM)

Проект по автоматизации прогнозирования спроса, управления запасами и оптимизации цепочек поставок для малых и средних предприятий.

## Технологии проекта

**Бэкенд:** Python, FastAPI, PostgreSQL, SQLAlchemy, Celery, Redis, JWT

**Фронтенд:** React, TypeScript, Vite, Ant Design, Axios

**Аналитика и ML:** Pandas, NumPy, scikit-learn, TensorFlow, Prophet (прогнозирование спроса)

**Десктоп-компонент:** Electron

**Инфраструктура:** Docker, GitHub Actions, Nginx

**Интеграции:** API поставщиков, WMS-системы, 1С, Excel
